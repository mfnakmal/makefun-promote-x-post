This repository holds POST.json naming the X post that quotes make.fun's make-your-own-bounty post, with a screenshot of the bounty-entrants-03 leaderboard (mfnakmal rank 5, on track for $20) as its photo. The post is the entry: the house reads its replies, reposts and quotes from X, and the top 50 share $250.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies POST.json to `out/POST.json`, where the gate reads it.
